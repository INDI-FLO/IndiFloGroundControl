
# IndiFloGroundControl UI Customization Guide

## Overview

IndiFloGroundControl contains IndiFlo-specific visual and functional customization implemented primarily using Qt Quick and QML.

---

## Branding

The application includes IndiFlo-specific:

- Application name.
- Logo.
- Icons.
- Resource files.
- Organization information.
- Domain information.
- Visual styling.

---

## Fly View

The Fly View has been customized with IndiFlo-specific flight-display elements.

Customization includes:

- Flight toolbar.
- Telemetry.
- Compass.
- Artificial horizon.
- Gimbal controls.
- Glass-style panels.
- Map-related presentation.

---

## Glassmorphism

Selected UI elements use a transparent/glass-style visual design.

Typical characteristics include:

- Semi-transparent backgrounds.
- Rounded corners.
- Subtle borders.
- Transparent panels.
- Consistent spacing.
- High-contrast text.
- Layered flight-display presentation.

---

When modifying telemetry:

Maintain readability.
Avoid duplicated telemetry bars.
Preserve telemetry bindings.
Check the complete Fly View.
Test different window sizes.
