
# IndiFloGroundControl Release Guide

## Purpose

This guide describes the validation process for preparing an IndiFloGroundControl build for testing or release.

---

# Application Validation

Verify:

Application starts.
IndiFlo branding is correct.
Logo is correct.
Main views load.
Fly View loads.
Plan View loads.
Vehicle Setup loads.
Settings load.


# Flight Display Validation

Verify:

Telemetry.
Compass.
Artificial horizon.
Gimbal interface.
Toolbar.
Map.
Vehicle status.
