
# IndiFloGroundControl Developer Guide

## Overview

IndiFloGroundControl (IGC) is an IndiFlo-customized ground control station based on the QGroundControl open-source project.

The project combines:

- C++
- Qt 6
- Qt Quick
- QML
- CMake
- MAVLink
- PX4
- Gazebo
- Linux/WSL2 development
- Windows development

IndiFlo-specific development includes application branding, flight-display customization, gimbal control, artificial-horizon instrumentation, compass customization, telemetry presentation and simulation integration.
